read

Read a file from the session's working directory.

What it does

Returns the file's text, optionally a window of its lines. Paths are resolved inside the session's working directory and refused if they would leave it (Sessions).

ParameterMeaning
pathRelative to the session's working directory. Required.
offsetLines to skip. Optional.
limitLines to return. Optional; absent means to the end.

Reading past the end is not an error

An offset beyond the last line returns nothing and succeeds. How long a file is is a fact about the file, and a caller paging through one learns it by reaching the end — not by being handed a failure that reads like a broken path.

A missing file is an error, and the two cases must not be confused: nothing to read at line four hundred is not the same as nothing to read at all.

A skill's file is read with skill_read

A skill's scripts run from its folder, outside the working directory, so the agent sees that path and reaches for read. Told only that the path was outside the workspace, it found skill_read on its next call, in five voice-over conversations out of five. So a refused path in the folder of a skill the conversation has names the call that reads it: skill_read {"name": "voice-over", "file": "scripts/place_chunks.py"}. A path anywhere else, a skill the conversation does not have included, is only refused.

Acceptance criteria

  • A file's full text is returned when no window is given.
  • An offset skips that many lines; a limit returns at most that many.
  • An offset past the end returns an empty result and succeeds.
  • A limit larger than what remains returns what remains.
  • A missing file fails and names the path.
  • A path that would resolve outside the session's working directory is refused.
  • A path in the folder of a skill the conversation has is refused with the skill_read call that reads it.
  • An empty file is returned as empty and does not fail.
