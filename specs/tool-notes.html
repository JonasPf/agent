notes

Short freeform notes that outlive a conversation.

What it does

Keeps a list of short texts, added one at a time and listed newest first. A note is never loaded into a prompt, and influences nothing unless it is asked for.

ActionDoes
addAppends one note. Requires text.
listReturns recent notes, newest first. This conversation's, unless session says otherwise.
ParameterMeans
textThe note, when adding.
sessionWhere to look, when listing. Omitted is this conversation; "all" is every conversation; a session id is that one.

What it is for

It is the demonstration that a tool may own storage. It declares a db_prefix, creates its tables from a schema.sql applied at load, and ships a panel that reads them back through the API — the full shape of a tool with state, in the smallest thing that needs one.

A note is scoped the way a search is. Listing returns the calling conversation's notes unless it asks to widen, which is the shape session_search already has and is there for the same reason: reading another conversation is something the operator should be able to watch being decided, so it appears in the transcript as the call it is (ADR-055).

A note records which session wrote it, and that is what the scope is read from. Notes still outlive the conversation that wrote them, which is the whole reason they are not simply written to a file in the session's working directory — but outliving a conversation is not the same as belonging to every one, so a note written elsewhere is reached by asking for it.

Acceptance criteria

  • add appends a note and confirms it was stored.
  • add with empty text is refused.
  • list returns notes newest first.
  • list on an empty store says it is empty rather than returning nothing.
  • A note records the session that wrote it.
  • list with no session returns the calling conversation's notes and no others.
  • list with session:"all" returns every conversation's notes, and with a session id returns that conversation's.
  • A listing that found nothing in this conversation says how to widen it.
  • Notes never appear in any system prompt.
  • The tool's tables all begin with its declared prefix.
  • The interface panel reads the tool's own tables through the API rather than the database directly.
