write

Create or replace a file in the session's working directory.

What it does

Writes the content to the path, creating parent directories as needed and replacing the file whole if it exists. Paths are confined to the session's working directory.

ParameterMeaning
pathRelative to the session's working directory. Required.
contentThe entire new contents. Required.
It replaces; it does not append. A write is the whole file. Changing part of a file is edit, which refuses an ambiguous match — where a partial write through this tool would silently discard everything it did not mention.

The result names the path and the number of bytes written, so a write of empty content is visible as one rather than reading like a call that did nothing.

Acceptance criteria

  • A file is created with exactly the content given.
  • An existing file is replaced whole.
  • Missing parent directories are created.
  • Empty content writes an empty file and says that it wrote zero bytes.
  • The result names the path and the byte count.
  • A path that would resolve outside the session's working directory is refused.
