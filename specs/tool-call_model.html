call_model

One call to another model: text, speech, transcription, or a decision.

What it does

A conversation runs on one model. This tool reaches any other the gateway lists for a single call, and the model named decides what the call is (ADR-070):

The modelIs sentReturns
writes textprompt as the request, each of files attached as what it is — image, audio, video, PDF, or text — and reasoning when givenits answer
speaksprompt as the words to say, exactly as written, in voicethe path of the audio written into the conversation's directory, at output when given: an mp3, or a WAV from a model that gives only raw samples, as Gemini's do
transcribesthe one audio file in files, and language when giventhe transcript, and with timestamps each segment's start and end in seconds
decidesprompt as the state, and questions as given; no fileseach question's answer, with its confidence where the model gives one

Given list — text, speech, transcription, or decisions — and no model, it calls nothing and lists the models of that kind instead, with what they cost and, for speech, their voices; prompt then narrows the list, every word matching the model's id or name. That is how the agent finds a model to name.

The agent makes the call, not the tool: the tool hands the request to the tool API, naming files by path, and the agent reads them from the calling conversation's directory, calls the gateway with its own key, writes audio back there, and adds the cost to the conversation's. Every result says what the call cost, except one that spoke: the gateway knows what speech cost only some fifteen seconds after the audio, and a voice-over of ten lines should not wait two and a half minutes for its bills. That cost is added to the conversation when the gateway reports it.

Why one tool and not one per kind. What differs between them is the model, and the model is a parameter. A tool per kind would be a tool to add every time the gateway offered another kind of output. The cost is a parameter whose meaning moves with the model: prompt is an instruction to a model that writes, and the very words to say to one that speaks. The description says so, and an eval case holds each.

What the model cannot take is refused before anything is sent: a file of a kind the model does not accept, naming the kinds it does; a file outside the conversation's directory; more than 20 MB of files in one call, which is what the gateway is sent inline. A longer recording goes as its audio, extracted with ffmpeg first.

ParameterMeaning
modelThe model to call, as the gateway names it. Required unless list is given.
promptThe request; the words to say; the state to decide on; or, with list, words to narrow it by.
filesPaths in the working directory to send with the call.
voiceFor a model that speaks: one of its voices.
outputFor a model that speaks: where to write the audio. Default speech-<time>.mp3; a WAV takes .wav in place of .mp3.
languageFor a model that transcribes: the recording's language, as an ISO 639-1 code.
timestampsFor a model that transcribes: return timed segments.
reasoningFor a model that writes and reasons: low, medium, or high.
questionsFor a model that decides: questions keyed by a name of your own, each with type (noul, choice, or score), instructions, and, for a choice or a score, criteria.
listInstead of calling: list the models of this kind.

Acceptance criteria

  • A model that writes text is sent the prompt with each file attached as its kind, and the reasoning effort when given; its answer is the result.
  • A model that speaks is sent the prompt as the words to say, in the voice given; the audio is written into the conversation's directory and the result names the file.
  • A model that gives only raw samples is asked for them when it refuses mp3, and they are written as a WAV of the rate and channels the gateway names.
  • A model that transcribes is sent its one audio file; the result is the transcript, with each segment's times when timestamps are asked for.
  • A model that decides is sent the prompt as the state and the questions as given; the result is each question's answer.
  • Listing a kind calls no model and returns that kind's models with their prices, and for speech their voices.
  • A file the model does not accept is refused before anything is sent, and the refusal names what the model accepts.
  • A path outside the conversation's directory, or more than 20 MB of files, is refused before anything is sent.
  • Every call's cost is added to the conversation's cost and stated in the result, except speech's: the gateway reports that some seconds after the audio, so the call returns without it and the cost is added to the conversation once reported.
  • The gateway's key is never given to the tool.
