API

The gateway's HTTP surface. The machine-readable document is openapi.json.

There is no authentication. Reaching the gateway over the tailnet is the only access control, as described in ADR-005.

Streaming

A WebSocket at /ws carries everything that changes: transcript entries as they are appended, token deltas during generation, job ticks, dead letters, and circuit breaker transitions.

The socket is a convenience, not a separate source of truth. Every state change delivered over it is also retrievable from the endpoints below, so a client that misses messages recovers by reading rather than by replaying.

Acceptance criteria

  • A client that disconnects and reconnects recovers current state from the HTTP endpoints alone.
  • Token deltas carry the session and entry they belong to.
  • The socket requires no authentication handshake.
